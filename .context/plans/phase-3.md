# Phase 3 — Admin Frontend

## Status
- `draft`

## Scope
- Admin app foundation with auth, layout, datatable, user management.

## Tasks
- Bootstrap Next.js admin app with query, state, form, UI dependencies.
- Implement auth/session flow + route protection + token refresh handling.
- Build admin layout (sidebar/header/breadcrumb/theme).
- Build generic DataTable (search/sort/pagination/bulk actions).
- Implement user management CRUD pages.

## Acceptance Criteria
- Login/logout and protected routes work reliably.
- DataTable is reusable for new resources.
- User management supports avatar upload (fast path, `useMediaLibrary=false`).
